# Sameeralam3127 Tap

Homebrew formulae maintained by [@sameeralam3127](https://github.com/sameeralam3127).

## Formulae

| Formula | Description |
| --- | --- |
| [`ipmg`](https://github.com/sameeralam3127/ipmg) | IP management and ping monitoring tool |

```sh
brew install sameeralam3127/tap/ipmg
```

Only scan networks you are authorized to scan.

## How do I install these formulae?

`brew install sameeralam3127/tap/<formula>`

Or `brew tap sameeralam3127/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "sameeralam3127/tap"
brew "<formula>"
```
